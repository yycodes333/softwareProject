    打开并加载商品详情

GET STARTED

装好插件，
开始第一次提取。

当前提供本地安装方式，使用桌面版 Chrome 的「加载已解压的扩展程序」即可。

Chrome 扩展管理地址chrome://extensions/

请在 Chrome 地址栏手动输入上方地址。

插件需在电脑上安装，手机可浏览此指南。
  1. 1

    准备插件文件

    获取本项目插件源码并解压。确认目录中包含 manifest.json。当前网站未提供公开安装包。

  2. 2

    打开扩展管理页面

    在桌面 Chrome 地址栏输入 chrome://extensions/ 并打开。

  3. 3

    开启「开发者模式」

    找到页面右上角的开关并开启。

  4. 4

    加载已解压的扩展程序

    点击同名按钮，准备选择插件文件夹。

  5. 5

    选择正确的插件目录

    选择包含 manifest.json 的目录，而不是 docs 官网目录。

  6. 6

    刷新商品页，开始使用

    返回商品详情页刷新，展开并加载图片，然后点击右下角「获取图片」。

为什么提取的图片不完整？

插件提取当前顶层页面已加载的图片，不会自动滚屏或读取未挂载的内容。请先展开详情并滚动加载，再重新提取；跨域 iframe 或特殊页面结构中的图片可能无法获取。

为什么有些图片下载失败？

可能与网络、图片域名权限、登录保护或 CDN 防盗链有关。插件会显示单图错误，支持筛选失败项重试，但不会绕过平台访问控制。

PNG 和修改文件后缀有什么区别？

修改后缀不会改变图片编码。插件会解码图片，再通过浏览器画布导出真正的 PNG。PNG 文件可能更大；动图会导出为静态帧。

插件会上传我的图片吗？

图片在本地浏览器中转换，不会上传到产品服务器。提取后预览和下载仍需要连接图片原站点或 CDN；提取记录保存在浏览器会话中。

手机能安装这个插件吗？

本插件面向桌面 Chrome 109 及以上版本。官网可以在手机上浏览，但不代表插件能在手机 Chrome 上安装运行。

下载后的图片保存在哪里？

默认保存到 Chrome 下载目录下的「电商图片」文件夹。若浏览器启用了下载前询问保存位置，仍可能弹出保存对话框。下载期间请保持结果页打开。
