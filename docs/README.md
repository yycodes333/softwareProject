# 电商图片提取器 · 静态官网

原生 HTML / CSS / JavaScript，无框架、无外部 CDN、无需构建。仅新增 docs 文件，不修改插件业务代码。首屏使用本地 SVG 商品插画和 HTML/CSS 界面示意，并非真实截图。

## 本地预览

直接使用浏览器打开 `docs/index.html` 即可阅读；推荐通过本地 HTTP 服务预览完整交互。在项目根目录运行：

`python -m http.server 8086 --bind 127.0.0.1 --directory docs`

然后访问 http://127.0.0.1:8086/ 。已有预览服务时无需重复运行。终端按 Ctrl+C 停止服务。

## 文件说明

- `index.html`：产品介绍、六项功能、三步使用流程、六步安装、常见问题和页脚。
- `css/style.css`：响应式布局、移动导航、焦点与减少动画适配。
- `js/main.js`：移动菜单、复制地址与年份更新。
- `assets/logo.svg`：品牌图标与 favicon。
- `assets/product-*.svg`：本地原创商品示意插画。

## 部署

可把 docs 文件夹内的全部内容上传到任意静态网站托管服务的网站根目录。所有资源均为相对路径，也支持部署在子目录中。

使用 GitHub Pages 时，先由你创建仓库并推送代码；在仓库 Settings → Pages 中选择从分支部署，选定包含代码的分支和 `/docs` 目录。此项目当前未替你创建远程仓库、上传文件或执行正式部署。

## 安装包入口

当前项目没有公开安装包、仓库链接或 Chrome 商店地址，因此页面主要按钮跳转到安装指南，不提供虚构下载链接。

后续如需发布安装包：将仅包含扩展所需文件的 ZIP 放入 `docs/downloads/`，然后在 index.html 增加真实相对路径链接，例如 `downloads/image-collector.zip`。请先确保 ZIP 确实存在，并调整安装步骤的「获取插件源码」文字。避免把 web-sum、node_modules 等无关内容打包。也可在拥有真实仓库/商店地址后加入对应链接。
